## 🖤 1Panel 炫彩深黑主题安装指南

本教程将指导你如何通过 **Tampermonkey（油猴）** 脚本，为 1Panel 面板换上酷炫的深黑皮肤。

---

### 📝 安装步骤

#### 1. 创建新脚本
点击浏览器右上角的油猴图标，选择 **“添加新脚本”**。

#### 2. 配置生效范围（关键步骤）
在脚本编辑器中，找到 `// @match` 部分。你需要将其修改为你 **1Panel 面板的实际访问地址**。

> **修改示例：**
> 如果你的面板地址是 `[http://192.168.1.1:37573](http://192.168.1.1:37573)`，则代码应改为：
> `// @match        [http://192.168.1.1:37573/](http://192.168.1.1:37573/)*`
<img width="836" height="311" alt="image" src="https://github.com/user-attachments/assets/5cfa63cb-6acd-4f04-a8e6-f12e6b89afc4" />

#### 3. 粘贴代码并保存
将主题脚本的完整代码粘贴到编辑器中，覆盖原有内容，然后按 `Ctrl + S`（或点击文件 -> 保存）。

---

### 💡 配置小贴士

*   **多地址适配**：如果你通过域名和 IP 两种方式访问，可以添加多行 `@match`：
    ```javascript
    // @match        http://192.168.1.1:37573/*
    // @match        https://panel.yourdomain.com/*
    ```
*   **立即生效**：保存脚本后，回到 1Panel 页面刷新（F5），即可看到暗黑皮肤效果。

---

### ⚠️ 注意事项
> [!IMPORTANT]
> 请务必确保 `@match` 后面的端口号与你安装 1Panel 时设置的端口一致，否则脚本将无法在该页面运行。
