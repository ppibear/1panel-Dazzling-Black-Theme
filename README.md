# 1panel-Dazzling-Black-Theme 耀眼黑色主题 使用教程
📖 教程介绍
本教程适用于 1Panel 服务器运维面板，通过油猴脚本安装 Dazzling-Black（耀眼黑色） 炫酷暗黑主题，修改面板原生白色界面，优化视觉观感、降低强光刺眼感，适配浏览器所有访问方式。
报错说明：访问 http://192.168.1.1:37573/ 出现URL拼写错误为本地端口访问常态提示，仅需修改脚本内端口即可正常适配。
🔧 前置准备
1. 必备软件
- 浏览器：Chrome、Edge、火狐等主流浏览器
- 油猴插件：Tampermonkey（必须安装，脚本运行依赖）
- 主题脚本：1panel-Dazzling-Black-Theme.user.js（油猴专用后缀）
📥 安装步骤
第一步：安装油猴插件
1. 打开浏览器，应用商店搜索 Tampermonkey；
2. 下载并安装官方正版插件，启用插件；
3. 安装完成后，浏览器右上角显示油猴图标即为成功。
第二步：修改脚本端口（关键步骤）
1. 右键点击主题脚本 1panel-Dazzling-Black-Theme.user.js，使用记事本/代码编辑器打开；
2. 找到脚本头部匹配规则代码：如图
        // @match        http://192.168.1.1:37573/*

<img width="836" height="311" alt="image" src="https://github.com/user-attachments/assets/5cfa63cb-6acd-4f04-a8e6-f12e6b89afc4" />

4. 修改说明：将端口 37573 修改为你自己的 1Panel 访问端口；
5. 保存文件，端口修改完成。
💡 补充知识：/* 为通配符，代表适配该端口下所有页面，保证面板全局生效黑色主题。
第三步：导入安装脚本
1. 打开已安装好的油猴插件，进入【仪表盘】；
2. 将修改好端口的 .user.js 脚本，直接拖拽进浏览器页面；
3. 弹出安装弹窗，点击【安装】，等待1秒安装完成；
4. 在油猴脚本列表，确认该黑色主题脚本为启用状态。
✅ 生效测试
1. 打开浏览器，输入你的 1Panel 访问地址（修改后的端口）；
2. 刷新页面，面板自动切换为 Dazzling-Black 耀眼黑色主题；
3. 若未生效：检查脚本是否开启、端口是否填写错误、刷新浏览器缓存。
❓ 常见问题解决
1. 访问地址提示URL拼写错误
原因：默认端口与个人1Panel端口不匹配，严格按照第二步，修改脚本内 @match 后的端口为自己的面板端口即可。
2. 脚本安装后无效果
- 确认脚本后缀为 .user.js，普通 .js 文件油猴无法识别；
- 关闭浏览器广告拦截插件，避免脚本被拦截；
- 清空浏览器缓存，强制刷新页面（Ctrl+F5）。
3. 如何关闭/卸载主题
进入油猴仪表盘，找到本主题脚本，关闭开关即可临时禁用；删除脚本即可彻底卸载，恢复原生白色界面。
